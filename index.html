05 / About

Make it work.
Then make it feel right.

Linux and Android are the main lanes, but the part I enjoy most is finding out how each layer fits together.

I'm Leon.

I work on Android apps, Android TV experiences, Linux desktop projects, and low-level platform experiments. My projects range from small utilities to ambitious desktop systems.

I care about functional software with a considered interface: clear interactions, useful defaults, and an honest understanding of what is working versus what is still a prototype.

Most projects are open source so the code, current state, and next steps are visible.
