whoami?.

I'm Leon Sony, a Linux, Android & low-level developer interested in software that sits close to the platform. That means Android apps, Android TV, Linux desktops, system experiments, and open source.

Most of what I build sits around Android and Linux: applications, TV experiences, desktop projects, system experiments, and open-source tooling.

My favorite workflow is simple: idea → code → build → test → break something → understand it → fix it → polish it.

I like making software where you can see the connection between the code, the system, and the machine underneath.
