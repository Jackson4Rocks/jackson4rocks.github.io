(01) About

Make it work.
Then make it feel right.

Linux and Android are the main lanes, but the part I enjoy most is finding out how each layer fits together — reading logs, tracing a bug, and learning a new layer the hard way when the easy one isn't enough.

I'm Leon. I work on Android apps, Android TV experiences, Linux desktop projects and low-level platform experiments — from small utilities to an entire desktop shell.

I care about functional software with a considered interface: clear interactions, useful defaults, and being honest about what works and what's still a prototype. Most of it is open source, so the code, current state and next steps are visible.

01 — Desktop OS · Arch + WaylandActive development

GlyphOS

Every detail. By design.

An independent, Nothing-inspired desktop built on Arch Linux and Wayland — with its own shell, command bar, control center and a design-token theme engine. Every value on screen comes from real system state.

02 — Android launcher · Small screensIn development

Cipher Launcher

Two PINs, two experiences.

A watch-first launcher for tiny Android devices. A glanceable Watch Mode and a full Launcher Mode live behind separate PINs, so each space stays independent.

Kotlin/ Android/ Launcher/ AMOLED

OneGlyph

Make the one dot do more.

The Nothing Phone (3a) Lite has a single Glyph dot. OneGlyph puts it to work — music reactions, notification cues, Morse code, timers, a metronome and charging feedback.
